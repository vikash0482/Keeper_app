# Keeper App 📝

A simple and responsive note-taking application built with React.  
This project was created while learning React from Angela Yu's Full Stack Web Development course.

---

## 🚀 Features

- Add new notes
- Delete notes
- Dynamic UI using React Components
- React Hooks (`useState`)
- Clean and responsive design
- Material UI Icons integration

---

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6)
- HTML5
- CSS3
- Material UI

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/keeper-app.git
```

Navigate to the project folder:

```bash
cd keeper-app
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```
